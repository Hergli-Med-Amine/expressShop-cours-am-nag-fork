
## Prérequis

- Node.js 22 ou 24 (version LTS), avec npm
- Git
- Visual Studio Code, avec l'extension **Jest** (identifiant `orta.vscode-jest`)

Vérification :

```
node --version    # v22.x ou v24.x
npm --version
git --version
```

## Démarrage

```
npm install       # installe Jest dans node_modules/
npm test          # attendu : 2 tests réussis
```
